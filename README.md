# CLIPFORGE AI

CLIPFORGE is a browser-based video clipping tool focused on finding and previewing strong moments in a video the user owns or has permission to edit.

## Current production app

- https://clipforge-ai-beta-two.vercel.app

## Current capabilities

- Local video upload and preview
- Heuristic Best Moment Finder
- Manual clip selection and trimming
- Aspect-ratio and framing controls
- Subtitle generation and burn-in export
- MP4 export

## Important source note

This repository is being prepared as the source-control home for the existing Vercel project. The production site's complete source has not yet been imported into this repository. Do not treat this README as the application source or connect this empty scaffold to production deployments yet.

## YouTube links

YouTube links are preview references only. CLIPFORGE scans and exports a selected local video file; it does not download or extract arbitrary YouTube videos.
